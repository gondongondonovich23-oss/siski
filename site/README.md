# TECHNOVA — техника с характером

Самодостаточный демонстрационный сайт магазина техники: без сборки и зависимостей.

## Состав

- `index.html` — вся страница (главная, каталог, корзина, оформление заказа, модальные окна)
- `styles.css` — стили и адаптивная вёрстка
- `data.js` — данные 16 товаров и 6 категорий
- `script.js` — каталог, фильтры, поиск, избранное, корзина, заказ, 3D-наклон фотографий
- `images/products/<id>/1..3.jpg` — по три фотографии каждого товара на чёрном фоне
- `fonts/` — шрифты Unbounded, Manrope, IBM Plex Mono (woff2)
- `SOURCES.md` — источники и ссылки на первоисточники фотографий

## Запуск

Откройте `index.html` в браузере или поднимите любой статический сервер из этой папки:

```bash
npx serve .
# или
python -m http.server 5173
```

## Возможности

- 16 товаров, 6 категорий, фильтры, поиск, сортировка
- Избранное и корзина сохраняются в localStorage
- Быстрый просмотр товара с тремя фотографиями и переключением
- 3D-наклон фотографий при наведении (мышь)
- Адаптивная вёрстка, тёмная тема, доступность (фокус, aria)

Демонстрационный проект: цены, бренды и фотографии не являются реальным предложением.

# Источники фотографий

Все фотографии товаров подобраны из открытых источников интернета через поиск Яндекс Картинки и показаны на чёрном фоне — по три на каждый товар.

## Как подбирались

- По каждому товару выполнялся поисковый запрос (название устройства + «на чёрном фоне»).
- Из результатов отбирались фотографии с тёмным/чёрным фоном и хорошим размером.
- Источники — открытые страницы: DNS, BigGeek, Яндекс Маркет, обзоры и медиа.

Перед публикацией фотографии следует заменить на собственные или лицензированные (например, с Pexels, Unsplash или Wikimedia Commons) и обновить этот файл ссылками на первоисточники.
